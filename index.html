04 / HOW I APPROACH PROBLEMS

Think clearly.
Test step by step.

Sample troubleshooting topics based on common development tasks. Replace these drafts with the actual problems, diagnostics, fixes, and lessons from your own experiences.

01 Website cannot connect to database ＋

Possible causes: MySQL service is stopped or connectivity details are incorrect.

Fix approach: Check the database credential, server status, and connection script.

02 PHP page reports an undefined function ＋

Possible causes: Missing function definition, incorrect include file, or a typo in the function call.

Fix approach: Confirm the function exists and the file is correctly included before the call.

03 Website works locally but not on hosting ＋

Possible causes: File paths, case-sensitive filenames, or environment mismatch.

Fix approach: Check relative paths, hosting restrictions, and basic deployment setup.

04 User cannot log in ＋

Possible causes: Validation errors, incorrect credentials, or an auth flow issue.

Fix approach: Validate the form input, confirm session handling, and review the login logic.

05 Excel results do not look correct ＋

Possible causes: Incorrect formula ranges, duplicate data, or wrong filtering logic.

Fix approach: Review the data source, formulas, and reference ranges before finalizing the report.
