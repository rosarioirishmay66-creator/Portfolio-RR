04 / HOW I APPROACH PROBLEMS

Think clearly.
Test step by step.

Sample troubleshooting topics based on common development tasks. Replace these drafts with the actual problems, diagnostics, fixes, and lessons from your own experience.

01 Website cannot connect to database ＋

Possible causes: MySQL service is stopped or connection settings are incorrect.

What I would check: Verify credentials, service status, host config, and whether the database exists.

02 PHP page reports an undefined function ＋

Possible causes: Missing function definition, include path issues, or a naming mismatch.

What I would check: Confirm the file is included correctly and the function is spelled consistently.

03 Website works locally but not on hosting ＋

Possible causes: File paths, case-sensitive filenames, or deployment configuration differences.

What I would check: Compare the serving environment and confirm the hosting setup matches the code.

04 User cannot log in ＋

Possible causes: Validation errors, incorrect credentials, or an authentication flow problem.

What I would check: Inspect input data, form logic, and database records.

05 Excel results do not look correct ＋

Possible causes: Incorrect formula ranges, duplicate data, or formatting mistakes.

What I would check: Review source tables, formulas, and data cleaning steps before finalizing the report.
